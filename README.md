# Rahatul Islam — Personal Portfolio

A responsive dark-themed portfolio website with a photo gallery. The images included are only the photos supplied by the user in this conversation.

## Project files
- `index.html` — website content and sections
- `style.css` — visual design, responsive layouts, and animations
- `script.js` — mobile navigation and photo lightbox
- `assets/` — optimized copies of the uploaded photos

## Preview
Extract the ZIP, then open `index.html` in a browser. The website works without a build step. Google Fonts are loaded online; fallback fonts are used if offline.

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the entire `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Choose deployment from the `main` branch and the root (`/`) folder, then save.
5. Wait for GitHub Pages to publish the site.

- To change the profile photo, replace `assets/profile.jpg` with your chosen image using the same filename.
